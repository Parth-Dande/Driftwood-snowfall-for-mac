Features

Small app. Real physics.

Gravity, air drag and shared gusts of wind. Big flakes fall faster, leaves rock as they fall, and no drift ever forms the same way twice.

🪟

Knows your windows

Move a window and its snow rides along. Shake it and the snow flies off both sides. Resize it and only the unsupported strip falls.

🖱️

Reacts to your pointer

Brush snow off a ledge, scatter leaves and money, and gather fireflies by holding still.

🖼️

Your own wallpaper

Put any picture behind a theme's weather, and go back to the original whenever you like.

🖥️

Every display

Runs on all connected screens, each with its own snow.

🚀

Stays out of the way

Lives in the menu bar, leaves the Dock, and can open at login. Clicks pass straight through the weather.

🔒

Private

Works offline, asks for no system permissions and collects nothing. It only reads where windows are, never what is in them.

Performance

You will not notice it running.

Most weather apps redraw every particle on every frame. Driftwood works out each particle's whole path once and hands it to the macOS compositor to play back.

~0.5%of one CPU core at default settings
120 Hzmotion at your display's own refresh rate

0work under full-screen apps or a sleeping display

Install

Up in a few minutes.

Driftwood is built on your own Mac from its source, so there is nothing unsigned to download.

Option 1: Install with an AI agent

Paste this prompt into any AI coding agent that can run commands on your Mac, such as Codex or Claude Code. It will check the requirements, build Driftwood, and open the installed app.

Install or update Driftwood on my Mac from the latest main branch of
https://github.com/Parth-Dande/Driftwood-snowfall-for-mac.
Please run the commands and complete the installation, rather than just
showing me instructions.

1. Check that this Mac runs macOS 14 or later and has Xcode or the Xcode
   Command Line Tools. If the tools are missing, run xcode-select --install
   and wait for me to finish Apple's installer before continuing.
2. Clone the repository into ~/Developer/Driftwood if it is not already
   there. If it exists, verify its origin is the repository above (the old
   Parth-Dande/driftwood URL is also valid), check for local changes, fetch
   origin, switch to main, and update with git pull --ff-only origin main.
   Preserve local work; stop and explain any conflict or diverged history.
3. Read the repository instructions and build script, then quit any
   running Driftwood app and run ./build.sh --install from the repository
   root. It builds in a temporary directory and installs one copy of the
   app, replacing the copy already in /Applications or ~/Applications, so
   no second Driftwood.app is left on this Mac. Wait for it to finish; it
   prints the installed path.
4. Verify the installed app with codesign --verify --deep --strict and
   confirm its executable contains both arm64 and x86_64 with lipo.
5. If any other Driftwood.app exists on this Mac, such as an older
   build/Driftwood.app in the repository, tell me where it is and ask
   before removing it. Request permission if the installed location
   requires elevated access.
6. Open the exact installed app path and confirm Driftwood is running.
   Tell me the installed path and source commit. I can then choose a scene
   and select Apply to All Displays.

Build locally from the checked-out source. Keep macOS security protections
in place; do not disable Gatekeeper or remove quarantine attributes.

To update, paste the same prompt again. The agent will fetch the latest main branch and rebuild your installed app while preserving local work.

Option 2: Install with Terminal

Get Apple's developer tools

Skip this if you already have Xcode or the Command Line Tools.

xcode-select --install

Download and install Driftwood

Paste this into Terminal. It builds the app and puts it in your Applications folder.

git clone https://github.com/Parth-Dande/Driftwood-snowfall-for-mac.git
cd Driftwood-snowfall-for-mac
./build.sh --install

Open it and pick a theme

Choose a theme and select Apply to All Displays. Driftwood lives in your menu bar after that.

open /Applications/Driftwood.app

To update, run git pull --ff-only origin main and ./build.sh --install again in the same folder.
